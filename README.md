# 日本中小型株スクリーナー（投資版 miyagi-kids）

日本の東証上場中小型株から、利益成長に対して株価がまだ十分に評価されていない
銘柄を、Pythonによる客観的な数値スクリーニングで毎週自動発掘し、
その後の実績まで検証し続ける個人用の投資研究サイトです。

## コンセプト

miyagi-kids が「イベント情報を自動収集→条件で絞り込み→おすすめ表示→毎週更新」
するサイトだったのと同じ発想で、このサイトは

```
市場データ収集
  → Pythonによる数値スクリーニング（100〜300銘柄に絞り込み）
  → 100点満点でスコアリング（上位50銘柄）
  → 上位20銘柄程度をAIが定性分析
  → 今週の注目株 TOP10 として掲載
  → 翌週以降の順位変動を記録
  → 過去の予測が実際にどうなったかを検証
```

を毎週自動で回します。**AIは銘柄を選びません。** ランキング・スコア・
5年シミュレーションはすべてPythonの数値計算であり、AIは「数値スクリーニング
を通過した候補について、なぜ面白い可能性があるのか」を強気材料・弱気材料・
確認事項に整理する役割だけを担います。

## システム構成

- 言語/DB: Python 3.11+ / SQLite（`data/stock.db`。リポジトリにコミットされ、
  週次実行のたびに更新されることで過去の記録を蓄積する）
- データ取得: J-Quants API V2（https://jpx-jquants.com/）
- AI分析: Anthropic API（任意。未設定でも数値ランキングまでは正常動作）
- サイト生成: Python + Jinja2 で静的HTMLを生成し GitHub Pages で公開
  （常駐サーバー・バックエンドAPIなし）
- 自動更新: GitHub Actions（毎週土曜 07:00 JST）

```
stock-screener/
├── config/settings.py     # 全ての閾値・重み・シナリオ前提
├── src/
│   ├── jquants_client.py  # J-Quants API V2 クライアント
│   ├── database.py        # SQLiteスキーマ・アクセス層
│   ├── data_loader.py     # データ取得オーケストレーション
│   ├── indicators.py      # 財務・株価指標の計算（欠損値はNoneのまま扱う）
│   ├── screener.py        # 数値条件による一次スクリーニング
│   ├── scoring.py         # 100点満点スコアリング
│   ├── forecast.py        # 5年シミュレーション（弱気/標準/強気）
│   ├── ranking.py         # カテゴリー別ランキング・順位変動
│   ├── ai_analysis.py     # AIによる定性分析（キャッシュ付き）
│   ├── performance.py     # 過去予測の実績検証（look-ahead bias防止）
│   ├── report.py          # 静的HTML生成
│   └── main.py             # 週次パイプライン全体のオーケストレーター
├── templates/              # Jinja2テンプレート
├── static/                 # CSS/JS
├── site/                   # 生成された静的サイト（GitHub Pagesに公開）
├── tests/                  # pytest（API非依存の単体テスト）
└── .github/workflows/update.yml
```

## J-Quants API

- 公式サイト: https://jpx-jquants.com/ でプランを選択して登録
- ダッシュボード「Settings > API Key」でAPIキーを発行し、`JQUANTS_API_KEY`
  環境変数に設定する（コードには一切書かない）
- V2 API はヘッダー `x-api-key` による認証（旧V1のリフレッシュトークン方式は
  廃止されている）
- ベースURL: `https://api.jquants.com/v2`
- 契約プランによって取得可能なデータ・レート制限が異なる（Freeプランは
  5リクエスト/分と非常に少ないため、対象銘柄数が多い場合は
  `--max-codes` で開発時の取得数を絞ることを推奨）
- 取得できないデータがあってもパイプライン全体は止まらず、「データなし」
  として扱われる（`errors` テーブルに記録）
- Freeプランのデータは「今日」までではなく、契約時点から一定期間トレールした
  範囲（例: 2024-05-21〜2026-05-21のように直近数か月分が欠けることがある）
  までしかカバーされない。`data_loader.py`はこの範囲外エラーを検知して
  自動的に取得可能な最新日付にフォールバックする
- `config/settings.py`の`MAX_CODES_PER_RUN`（環境変数`MAX_CODES_PER_RUN`でも
  上書き可、デフォルト120）で、1回の実行で価格履歴・決算・配当を取得する
  銘柄数の上限を制御する。5req/分のFreeプランでは1銘柄あたり3コール必要
  なため、上限なし（`0`）にすると時価総額条件に合致する銘柄数によっては
  数時間〜かかる。Light/Standard/Premiumプラン（60/120/500 req/分）に
  アップグレードした場合はこの値を大きくしてよい

## AI API（任意）

- `ANTHROPIC_API_KEY` を設定すると、スコア上位銘柄（既定20件）＋
  順位が大幅上昇した銘柄についてAIが定性分析を行う
- 未設定でもサイト全体（数値ランキング・5年シミュレーション等）は正常に動作する
- AI分析結果は `ai_analyses` テーブルにキャッシュされ、次の場合のみ再分析する:
  新しい決算が開示された／順位が大きく変動した／一定期間（既定90日）が
  経過した／入力データが変化した

## 環境変数

| 変数名 | 必須 | 説明 |
|---|---|---|
| `JQUANTS_API_KEY` | 実データ取得に必須 | J-Quants API V2 のAPIキー |
| `ANTHROPIC_API_KEY` | 任意 | AI定性分析を有効化する場合に設定 |

`.env` は `.gitignore` 済み。GitHub Actionsでは GitHub Secrets を使用する。

## ローカル実行

```bash
# 既存DBのデータだけでサイトを再生成（API呼び出しなし）
python -m src.main --skip-fetch

# 実データを取得して週次パイプラインをフル実行
python -m src.main

# 開発時: 取得銘柄数を絞ってAPI消費を抑える
python -m src.main --max-codes 30
```

生成された `site/index.html` などをブラウザで直接開くか、簡易サーバーで確認できます。

```bash
python -m http.server 8000 --directory site
```

## GitHub Actions

`.github/workflows/update.yml` が毎週土曜07:00 JST（cron指定はUTC 22:00金曜）に
以下を自動実行します。

1. J-Quantsデータ取得 → SQLite更新
2. 財務指標計算・数値スクリーニング・スコアリング
3. 5年シミュレーション
4. ランキング生成・順位変動記録
5. 必要な銘柄だけAI分析
6. 過去ランキングの実績評価
7. HTML生成
8. `data/stock.db` をリポジトリにコミット（履歴を消さないための唯一の永続化手段）
9. `site/` を GitHub Pages にデプロイ

`workflow_dispatch` にも対応しているため、手動実行も可能です。

## GitHub Pages 設定

リポジトリの Settings → Pages で「Source: GitHub Actions」を選択してください。
初回の Actions 実行後にサイトが公開されます。

## スコアリング（100点満点）

| カテゴリー | 配点 | 主な指標 |
|---|---|---|
| 成長性 | 30点 | EPS成長率・営業利益成長率・売上成長率・EPS CAGR |
| 割安性 | 25点 | PEG（最重視）・PER・PBR |
| 収益性 | 15点 | ROE・営業利益率・ROA |
| 財務健全性 | 10点 | 自己資本比率 |
| 業績モメンタム | 10点 | 通期進捗・直近増益率 |
| 株価位置 | 10点 | 52週高値からの下落率・200日線乖離率 |

単純な低PERランキングではなく、PER÷EPS成長率（PEG）を割安性評価の中心に
据えることで、「PER10倍・成長率5%」より「PER18倍・成長率25%」を高く
評価できるようにしています。

## AI分析

数値スクリーニング・スコアリングが完了した後、上位候補についてだけAIが
「強気材料・弱気材料・確認すべき事項・成長ドライバー・競争優位性」を
構造化して出力します。「買い」「売り」「絶対上がる」等の断定はさせず、
受注・市場シェア・契約内容など根拠のない具体的事実は書かせません。
確認できない場合は「情報を確認できませんでした」と表示されます。

## 5年シミュレーション

弱気・標準・強気の3シナリオで、5年後EPS = 現在EPS × (1+成長率)^5、
5年後株価 = 5年後EPS × 出口PER として機械的に計算します（AIは一切計算しません）。
画面上では常に「システム試算」であり将来を保証しないことを明記しています。

## ランキング履歴・成績検証

`ranking_history` テーブルは過去の行を一切削除しません。毎週のランキングは
すべて蓄積され、`history.html` から閲覧できます。トップページでは
過去6か月間に「今週の注目株」に選ばれた銘柄のTOP1/TOP3/TOP10について、
選定時点の株価から現在までの平均リターン・中央値・プラス比率を計算して
表示します。look-ahead biasを避けるため、各時点で入手可能だった情報のみを
使用しています。

## 注意事項

本サイトは投資研究・分析を目的とした個人用ツールです。将来の株価や利益を
保証するものではありません。掲載情報を利用した投資判断は利用者自身の
責任で行ってください。
